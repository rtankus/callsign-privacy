Privacy Policy for ATC Callsign Finder

Last updated: May 2026

ATC Callsign Finder is a Chrome extension designed to help users search FAA ICAO three-letter designators, airline telephony, aircraft information, and related callsign data.

Data Collection

ATC Callsign Finder does not collect, sell, transmit, or share personally identifiable information.

Local Storage

The extension uses Chrome storage only to save extension-related settings, cached lookup data, or temporary state needed for functionality. This data is stored locally in the user’s browser.

Permissions

The extension requests the following Chrome permissions:

  • storage: Used to save extension preferences and local lookup state in the browser.
  • tabs: Used only so the extension can detect or interact with supported aviation-related tabs when needed.

Host Permissions

The extension requests access to the following domains:

  • faa.gov: Used to access FAA aviation reference data relevant to ICAO designators and callsign lookup functionality.
  • globe.adsbexchange.com: Used to support callsign and aircraft lookup features on ADS-B Exchange Globe pages.
  • adsbexchange.com: Used to support callsign and aircraft lookup features on ADS-B Exchange pages.

Content Scripts

The extension includes a content script that runs only on supported ADS-B Exchange pages. It is used to support aviation lookup functionality on those pages and does not collect personal browsing history.

Remote Code

ATC Callsign Finder does not execute remote code. Extension scripts are packaged with the extension.

Analytics and Tracking

The extension does not use analytics, advertising trackers, telemetry services, or third-party tracking tools.

Data Sharing

The extension does not sell, rent, or share user data with third parties.

Web Accessible Resources

The extension includes local JSON data files such as aircraft, airline callsign, and flight-reference lookup files. These files are packaged with the extension and are used only to provide callsign lookup functionality.

Changes to This Policy

This policy may be updated if the extension’s permissions or functionality change. Updates will be posted on this page.

Contact

For privacy questions, contact the developer through the Chrome Web Store listing or the project repository.
