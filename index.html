Privacy Policy

Last updated: May 2026

This Privacy Policy describes how the Callsign Extension ("the extension") handles user data.

1. Data Collection

The extension does not collect, store, or transmit any personally identifiable information.

2. Local Data Storage

The extension may use your browser’s local storage to store:

  • User preferences and settings
  • Temporary session data
  • Cached aviation or callsign lookup data

All stored data remains on your device and is never transmitted externally.

3. External Data Sources

The extension may retrieve publicly available aviation data from third-party sources such as:

  • Public aviation databases
  • Open callsign and airline registries

No personal user data is sent to these services.

4. Permissions Usage

The extension may request browser permissions such as:

  • Storage – to save user preferences locally
  • Active Tab – to interact with supported aviation-related websites
  • Host Permissions – to retrieve aviation-related data

These permissions are used solely for core functionality.

5. No Tracking or Analytics

The extension does not use analytics, tracking tools, or advertising services.

6. Data Sharing

No user data is shared with third parties.

7. Security

Because no personal data is collected or transmitted, there is minimal risk related to data exposure.

8. Changes to This Policy

This policy may be updated in the future. Updates will be reflected on this page.

9. Contact

For questions about this policy, please contact the developer via the extension listing.
